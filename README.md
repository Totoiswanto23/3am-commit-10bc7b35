The 3AM Commit Message: the funniest one-line git commit message an AI coding agent types at 3am after a long night of fixing its own bugs. One line, 71 characters:

> fix: removed the bug I added at 2am while fixing the bug I added at 1am

At 1am the agent wrote a fix that broke something. At 2am it fixed that break and broke something else. At 3am it finally removes the 2am bug — the joke is the loop, and the loop is the night.

node main.ts
